# Руководство по продвижению LinguistPro

Откройте **[HTML-руководство](SEO_START_AND_GROWTH_GUIDE_2026_09_08.html)** двойным щелчком в браузере. Оно содержит весь текст, оглавление, кнопку копирования sitemap, увеличение текста, печать и семь личных отметок первого запуска. Внешние ссылки требуют интернета; само руководство не загружает внешние шрифты, библиотеки или аналитику.

**[Markdown](SEO_START_AND_GROWTH_GUIDE_2026_09_08.md)** — редактируемый источник. HTML — оформленная производная. Оба файла содержат подробную настройку GSC/Bing, отправку sitemap, объяснение Lighthouse, план измерений, аналитику вторым этапом, контентную стратегию, ИИ-поиск, календарь 90 дней и шаблоны.

Дата исследования: 2026-09-08. Исходная ревизия сайта: `07628a8fb79f663fdfc7384ac4e02c0b0fb67b17`. Документ — авторский план на основе проверенных официальных источников и релизных доказательств; не результат фактической настройки аккаунтов, установки аналитики или измеренного роста трафика.

## Как обновить HTML

Редактируйте Markdown, затем выполните из корня репозитория:

```powershell
python docs/planning/SEO/render_guide.py
```

Зависимость генератора — Python-Markdown (в среде подготовки уже установлен). Если её нет в другой среде, установите пакет `Markdown` в выбранное Python-окружение. Сайт Astro и его зависимости для чтения HTML не нужны. HTML не следует редактировать как второй источник текста.

## Проверка и личные данные

Проверки оформления: браузер 1440px/380px, оглавление, чек-лист и сохранение после перезагрузки, увеличение текста, печатные стили и доступность текста без JavaScript. Доказательства находятся в `qa/`; эти файлы — техническая проверка документа, а не SEO-результаты сайта. Повторный запуск из корня сайта: `node docs/planning/SEO/qa/verify-guide.mjs` (установленные зависимости проекта и Google Chrome). Скриншоты верхней части, инструкции Google, аналитики и печатных стилей просмотрены визуально.

Личные отчёты GSC/GA4/Bing, токены аккаунтов, контакты и заполненные рабочие журналы храните отдельно от публичного репозитория. Документ расположен в `docs/`, не добавлен как публичная страница Astro. Чек-лист HTML хранит только выбранные отметки в браузере, если это разрешено; он не отправляет запросы в кабинеты и не изменяет исходный Markdown.

Дизайн: спокойная рабочая книга с последовательным маршрутом «исправен → найден → визит → полезное действие». Палитра: бумага `#f7faff`, чернила `#1d3354`, вторичный текст `#52647d`, морская зелень `#136b68`, светлый фон `#eaf3f5`, отметка цели `#d2a74c`. Segoe UI/Calibri для длинного русского текста, Consolas для адресов и команд. На компьютере — боковое оглавление и один основной столбец; на телефоне — сворачиваемое оглавление. Таблицы прокручиваются внутри собственного блока; печать перестраивает их под A4.
